# AMAZON-SALES-ANALYSIS
 Interactive Tableau dashboard providing insights into Amazon's sales trends, product performance, and customer behaviour across regions, categories, and shipping methods.
 ## Live Tableau Dashboard

[View Interactive Amazon Sales Dashboard](https://public.tableau.com/views/TABLUEPROJECT_17402180450050/Dashboard1?:language=en-US&:display_count=n&:origin=viz_share_link)

## Key Features
- Quantity analysis by week and category
- Courier and shipping status analysis
- B2B sales quantity analysis
- Sales channel comparison
- Region-wise sales visualization
- Product size and category analysis

## Tools Used
- Tableau Public
- Data Visualization
- KPI Analysis
